# Pathfinding Visualizer – Professional Edition

An interactive **Pathfinding Visualizer built using Python and Pygame** that demonstrates how popular graph traversal and pathfinding algorithms work on a grid.

The application allows users to place start and end nodes, create walls, generate random mazes, and visualize algorithms step-by-step as they explore the grid and find the shortest path.

## Features
- Interactive grid-based visualization
- Multiple pathfinding algorithms
- Real-time algorithm animation
- Adjustable speed controls
- Random maze generator
- Wall drawing with mouse drag
- Clean professional UI

## Algorithms Implemented
- A* Algorithm
- Dijkstra's Algorithm
- Breadth-First Search (BFS)
- Depth-First Search (DFS)

## Controls
- **Left Click:** Place Start / End nodes and draw walls  
- **Right Click:** Remove nodes or walls  
- **Start Algorithm:** Run the selected algorithm  
- **Speed Buttons:** Adjust animation speed  
- **Random Maze:** Generate obstacles automatically  

## Technologies Used
- Python
- Pygame
- Object Oriented Programming
- Graph Traversal Algorithms

## Purpose
This project is designed to help understand **how pathfinding algorithms explore nodes and determine optimal paths in a grid-based environment** through real-time visualization.
